## Session handoff

- At the start of a session, review the handoff and run `git status`.
  When I say "continue," pick up the next task listed in the handoff.
- Before reporting that a milestone is complete, update `HANDOFF.md`
  with what changed, decisions the next session needs, test commands
  and results, any unfinished work, and the exact next task.
- If I say "handoff" mid-task, update `HANDOFF.md` with the current
  stopping point and how to resume.
- Keep `HANDOFF.md` short. Replace outdated status with the latest
  checkpoint. Leave commits and pushes for me unless I ask.
